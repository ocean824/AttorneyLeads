here’s a tiny, surgical UI patch that adds a “Discover” button to your CRM page. It uses saved defaults (practice area + location), shows a “Fetching…” toast immediately, then after the job finishes it shows “Saved N new prospects” based on the before/after count.

1) client/src/pages/crm.tsx — add helpers + quick-discover handler

Add right below your other handlers (after handleDiscoverProspects, before handleSheetsSync is fine):

// --- Quick Discover (saved defaults) helpers ---
const DEFAULTS_KEY = "crmDiscoverDefaults";

type DiscoverDefaults = { searchQuery: string; location: string };

const getDiscoverDefaults = (): DiscoverDefaults => {
  try {
    const raw = localStorage.getItem(DEFAULTS_KEY);
    if (raw) return JSON.parse(raw) as DiscoverDefaults;
  } catch {}
  // Safe fallback if nothing saved yet
  return { searchQuery: "Personal Injury law firms", location: "Florida" };
};

const handleSaveDefaults = () => {
  // Save whatever is currently typed into the inputs as the defaults
  const payload: DiscoverDefaults = { searchQuery, location };
  localStorage.setItem(DEFAULTS_KEY, JSON.stringify(payload));
  toast({ title: "Saved", description: "Defaults updated for quick discover." });
};

const handleQuickDiscover = async () => {
  const beforeCount = prospects?.length ?? 0;
  const { searchQuery: q, location: loc } = getDiscoverDefaults();

  // Immediate feedback
  toast({
    title: "Fetching…",
    description: `Discovering "${q}" in ${loc}…`,
  });

  try {
    await apiRequest("/api/crm/discover", {
      method: "POST",
      body: JSON.stringify({ searchQuery: q, location: loc, platform: "linkedin" }),
    });

    // Your backend fetches & saves asynchronously; wait a beat and then compute delta
    setTimeout(async () => {
      await queryClient.invalidateQueries({ queryKey: ["/api/crm/prospects"] });
      const fresh = (await queryClient.fetchQuery({
        queryKey: ["/api/crm/prospects"],
      })) as CrmProspect[];

      const afterCount = Array.isArray(fresh) ? fresh.length : beforeCount;
      const delta = Math.max(0, afterCount - beforeCount);

      toast({
        title: "Completed",
        description: `Saved ${delta} new prospect${delta === 1 ? "" : "s"}.`,
      });
    }, 6000);
  } catch {
    toast({
      title: "Discover Failed",
      description: "Could not start prospect discovery",
      variant: "destructive",
    });
  }
};

2) client/src/pages/crm.tsx — add the tiny Discover button in the Prospects header

Replace the Prospects CardHeader block:

<CardHeader>

How it behaves

Click Save as default once to store your preferred practice area (search query) + location.

Use the tiny Discover button (top-right of Prospects card) any time; it:

Shows “Fetching…” immediately,

Waits for your backend to finish saving,

Then shows “Saved N new prospects.”

No backend changes required—the button hits your existing POST /api/crm/discover and uses your already-wired PhantomBuster workflow.
