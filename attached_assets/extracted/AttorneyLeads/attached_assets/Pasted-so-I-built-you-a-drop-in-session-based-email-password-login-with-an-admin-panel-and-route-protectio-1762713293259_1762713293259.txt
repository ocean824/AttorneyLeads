so I built you a drop-in, session-based email/password login with an admin panel and route protection.

What I added

Users table (Drizzle)

users(id, email unique, passwordHash, role enum 'user'|'admin', isActive, lastLoginAt, createdAt, updatedAt)

Secure password hashing with Node’s built-in crypto.scrypt (no new deps) + constant-time verification.

Cookie sessions using express-session + connect-pg-simple (already in your deps).

Auth API

POST /api/auth/bootstrap (one-time: create first admin from env vars)

POST /api/auth/register (admin-only)

POST /api/auth/login

POST /api/auth/logout

GET /api/auth/whoami

Client

/login page (email + password)

Admin Users page: /admin/users (list, activate/deactivate, flip user/admin)

<PrivateRoute/> wrapper that gates all app routes

Header gets Login/Logout UI and Admin button when role=admin

Quick setup (5 minutes)

Env vars (add to your .env)

DATABASE_URL=<your Neon Postgres URL>
SESSION_SECRET=<random-long-string>
SESSION_COOKIE_NAME=sid
SESSION_TTL_MS=28800000
ADMIN_EMAIL=admin@example.com
ADMIN_PASSWORD=changeMeLong12Chars


Apply the patch

Drop the files from the zip into the same paths in your project (overwrite where they match).

Migrate DB

npm run db:push


This pushes the users table (the session table is auto-created by the store at runtime).

Run dev

npm run dev


Bootstrap first admin

POST /api/auth/bootstrap


(Only works if there are currently zero users.)

Login

Visit /login, sign in with ADMIN_EMAIL / ADMIN_PASSWORD

All app pages now require auth; admin sees an Admin button → /admin/users.

Security notes (already wired)
