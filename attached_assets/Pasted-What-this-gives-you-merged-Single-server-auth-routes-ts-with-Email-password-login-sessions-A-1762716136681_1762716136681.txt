Admin hard-gate TOTP (ENFORCE_ADMIN_TOTP_SETUP=true) — no fallback allowed until TOTP is enabled

TOTP setup & verify, backup codes (hashed), Email/SMS OTP fallback (Twilio optional)

Trusted devices (httpOnly cookie + hashed DB record; TTL configurable)

Password reset (email token, 30-min)

WhoAmI, logout, admin user list/patch, phone save, backup-codes PDF generation

Updated React pages with inserted controls:

/login → routes into 2FA or hard-setup mode automatically

/2fa-fallback → Email/SMS code + “Trust this device”

/account-security → enable/disable TOTP, save phone, generate backup codes + Download PDF

/devices → list/revoke trusted devices

Header → Login/Logout, Account, Admin links

PrivateRoute guard

forgot + reset pages for password reset

How to integrate (fast)

Schema

Merge shared/schema.MERGE_ADD.ts into your real shared/schema.ts.

Run: npm run db:push

Server

Overwrite/add files from the zip (notably server/auth-routes.ts and server/security/*).

Ensure your server initializes sessions (as in your prior patch).

No need for cookie-parser; the route parses cookies internally.

Client

Copy the provided pages/components.

Add the routes shown in client/src/App.ROUTES.MERGED.txt.

Env (minimum)

APP_URL=https://your-app-url
SESSION_SECRET=change-me-long
AUTH_ENC_KEY=<32+ char key>     # you generated earlier
